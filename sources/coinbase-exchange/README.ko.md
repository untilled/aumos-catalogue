# coinbase-exchange

Coinbase Exchange의 공개 시세 데이터. **입력할 키가 없습니다** — 이 경로들은 열려 있고, 여기
선언된 어떤 것도 계좌에 닿지 못합니다.

## 무엇을 얻는가

| | |
|---|---|
| **닿는 곳** | `api.exchange.coinbase.com` |
| **비용** | 무료, 가입도 필요 없음 |
| **자격증명** | **없음** |
| **이력** | `BTC-USD` **2016-01**부터, `ETH-USD` **2017-01**부터 |

```
/time
/currencies
/products
/products/{symbol}                 예: BTC-USD
/products/{symbol}/candles         ?granularity,start,end
/products/{symbol}/ticker
/products/{symbol}/stats
/products/{symbol}/book            ?level
/products/{symbol}/trades          ?limit
```

위의 모든 경로와 파라미터는 적기 전에 실제 API로 호출해 확인한 것입니다.

## 왜 이 벤더이고, 왜 달러 표시인가

크립토 가격 이력의 대부분은 **USDT** 표시입니다. 스테이블코인이죠. 그렇게 매겨진 계열은 그
코인의 위험을 안에 담고 있습니다 — 페그가 흔들리면 거기서 계산된 모든 수익률이 함께 흔들리는데,
숫자 자체는 그 사실을 말해주지 않습니다.

여기의 `BTC-USD`는 **실제 달러** 표시이고, 이 거래소의 얇은 보조 상장이 아니라 주력 호가창입니다.
더 깊은 USDT 시장 대신 이것을 고르는 이유의 전부가 그것입니다 — 이 위에서 잰 추세는 자산의
추세이지, 자산에 페그를 더한 것의 추세가 아닙니다.

## 캔들에 대해 네 가지

**⚠️ 컬럼이 OHLC가 아닙니다.** 한 행은

```
[ time, low, high, open, close, volume ]
```

저가와 고가가 시가·종가보다 **앞**에 옵니다. OHLC로 읽으면 시가가 저가와, 종가가 고가와 조용히
바뀌고, 그 결과도 여전히 가격 계열처럼 보입니다.

**⚠️ 행이 최신순으로 옵니다.** 차분하기 전에 정렬하십시오.

**한 번에 최대 300봉입니다.** 그보다 긴 구간은 잘린 답이 아니라
`granularity too small for the requested time range` 를 돌려줍니다 — 실패 방식으로는 이쪽이 낫지만,
1년치 일봉이 두 번의 호출이라는 뜻이기도 합니다. 겹쳐 받아 겹치는 구간이 일치하는지 확인한 뒤에
이으십시오.

**봉은 UTC 00:00에 시작합니다.** 24시간 시장에는 종가가 없으므로 *어느 봉이 완료된 것인가* 는
사실이 아니라 규약입니다. 이 문서는 그것을 정하지 않습니다. 읽는 에이전트가 자기가 쓴 규약을
밝혀야 합니다.

## 날짜가 붙지 않는 것

`ticker`·`stats`·`book`·`trades`는 **지금**에 답합니다. 그것을 옮길 파라미터가 없으므로, 과거의
시점에서 판단하는 에이전트에게 이것들은 오래된 숫자가 아니라 **미래에서 온 사실**입니다. 날짜가
있는 것은 `candles`로 물으십시오.

상품이 여전히 자기 자신인지를 묻는 곳은 `/products/{symbol}`입니다. `status`·`trading_disabled`·
`fx_stablecoin`을 담고 있고, 거래정지되거나 상장폐지된 페어를 그냥 한산한 페어와 구별하는 방법이
그것입니다.

## 이 문서가 담지 않는 것

- **거래소 하나입니다.** 교차 집계가 아니라 Coinbase 자신의 호가창입니다. 같은 분에 대한 다른
  거래소의 체결은 다를 것이고, 어느 쪽이 옳은지에 대해 이 문서는 의견이 없습니다.
- **현물만입니다.** 무기한물도, 펀딩도, 파생상품도 없습니다.
- **계좌에 닿지 않습니다.** 잔고·주문·체결은 다른 host에 있고 여기 선언되어 있지 않습니다.

## 당신이 제공하는 것

없습니다. 서명할 자격증명이 없으므로 Aumos는 이 소스에 대해 아무것도 서명하지 않고, 위 목록
바깥의 경로는 거부합니다.
